# Live recording

Choose a device with Settings → MIDI → Find MIDI inputs. MIDI access is requested only on discovery, without SysEx. Device selection is session-only; keyboard note input, count-in and the recording tick are saved UI preferences. Unsupported browsers and permission errors leave keyboard recording available.

Record live in the phrase inspector, duration popup or pattern popup starts a project-BPM loop. Phrase Count-in waits the first measure of the section (at least two beats), independently of the ongoing recording tick. Armed count-in repeats that measure until the first keyboard or MIDI note starts capture at the positioned playhead, including that triggering note. The button reads Arm recording, then Waiting for note while armed. Backtick starts/arms or stops phrase recording; Shift + backtick stops and removes the last recorded batch. Both shortcuts can be changed in Settings → Shortcuts → General. Rhythm editors retain their optional count-in. Stopping during count-in leaves no recording gesture. The phrase loop uses the phrase length; rhythm loops use four beats. In Settings → Shortcuts → General, Tap recording rhythm assigns the tap/hold key (backtick by default). Phrase recording uses physical key positions in row order: 1–0, Q–P, A–L, Z–M. For pitched phrases, Match scale/key defaults on and maps successive keys to the same scale degrees used by phrase scale/key snapping, using MIDI C2 as the base and preserving the project key and signed octave transposition. Turn it off for C-major white keys beginning at C2. The piano-roll gutter displays the current mapping, using lowercase for normal letters and uppercase for Shift variants, whenever the phrase editor is open. Normal labels take precedence when both reach the same pitch; hidden shifted aliases remain valid input. Labels share a fixed gutter column at comfortable zoom levels and alternate between two stable columns in dense views; label sizes fit the available vertical spacing. Shift raises the pitch one semitone. Text fields and shortcut capture retain native keyboard input.

In a drum phrase, keyboard keys and incoming MIDI notes address tracks in their displayed order for both audition and recording. The first track uses `1` or MIDI note 36, the second uses `2` or MIDI note 37, and so on. Keyboard positions continue through 1–0, Q–P, A–L, and Z–M. Hold Shift for tracks 37 and up. Each track sounds and records its assigned drum instrument, including when multiple tracks share an instrument. Unassigned keys are ignored.

Play other tracks defaults off in the phrase recording controls. When enabled, backing playback loops the edited absolute song region at the project BPM and excludes the edited track(s). Recording follows the transport audio clock, so the transport progress and arrangement playhead advance together. Backing starts after count-in/preparation and stops with recording, restoring the previous loop settings without editing the project.

Outside live recording in pitched phrases, with notes selected, matching phrase-editor actions and global actions (selection, transpose, delete, undo/redo and playback) take priority over keyboard audition. During live recording, note keys always take precedence, including Shift-letter keys with action bindings. Outside recording with no selection, letter and Shift-letter keys audition normally. Unbound note keys continue to audition when notes are selected, and held notes still release if selection changes. Ctrl/Cmd shortcuts remain available. Recovery applies to all keys: missing-code releases use the reported character, and a fresh non-repeat press can release/retrigger a key whose prior release was lost.

Phrase recording preserves free onset and release timing by default. Lock Grid opts into snapping onsets down to the current time cell and releases to the closest boundary, with at least one cell; held previews use the same choice. Rhythm editors retain their grid timing. Held notes split at loop boundaries. Patterns add hits while held. Duration recording writes sounded intervals while held and pauses during silence, independently of the manual note/pause drawing tool. Unvisited time retains its prior material until the cursor reaches it. Keyboard scale matching has its own preference, independent of drawing snap-to-scale; MIDI input in pitched phrases remains chromatic. MIDI velocity is retained; keyboard velocity is 90. Phrase input sounds through the selected instrument or MIDI output while held, with each sounding piano key highlighted until its final input source releases. With recording off, keyboard and MIDI input only audition, highlight keys and expand the pitch view; no provisional notes, phrase edits or history entries are created. Provisional notes grow continuously in the score, then become quantized draft notes on release. Live highlighting follows all held notes and clears during silence. Recording outside the current pitch view expands it to include the new pitches and the previously visible slice.

Discard on Loop defaults on: notes from an earlier pass are removed one measure into the next loop, including during silence. Stopping within that grace period keeps the previous pass along with notes already captured in the new pass. Notes already in the phrase before recording are preserved. Held notes continue into the new pass, retaining their earlier-pass segments until the grace period expires. Turn it off to layer all passes. The choice is saved as a UI preference. Each phrase recording session is one draft undo/redo step. Stop commits a pattern recording as one project gesture. Duration recording stays in the popup draft until Validate and Save; phrases stay in their draft until Apply or Local Apply. Blur, page exit, port changes and disconnects release held inputs. Starting another recorder stops the previous one. Input ownership returns to the underlying phrase editor when a popup closes, and unrelated dialogs leave their keyboard input untouched. Metronome scheduling uses Web Audio lookahead outside Angular rendering; the first beat of each measure is accented. Count-in positions the playhead at the recording start immediately: normal count-in uses the region start, and armed count-in retains an in-region position or resets an outside position to the start. Each audible count-in tick flashes the playhead for 100 ms with the theme accent hue rotated by 180 degrees. Tick boundaries and the beat counter follow the active loop length, including fractional sections.
