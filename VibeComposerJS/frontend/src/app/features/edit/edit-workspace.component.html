Editing gestures and shortcuts

Click empty space to add a note. Drag notes to move; drag either edge to trim. Alt+left drag trims the start. Shift bypasses the time grid and keeps move drags at the same pitch.

Right drag selects a box. Ctrl+right drag extends selection. Right-click deletes; Alt+right-click splits at the pointer. Ctrl+left drag on selected notes duplicates; elsewhere it shapes pitch.

Middle drag edits velocity; Alt+middle drag changes length; Shift+middle drag changes pitch. Ctrl+middle drag shapes velocities. Middle-click empty space exits: unchanged drafts cancel; edits to section overrides save locally; other edits save globally.

Ctrl/Cmd+A selects all, Delete removes selection, Shift+T opens transpose, Ctrl/Cmd+Z undoes, Ctrl/Cmd+Y or Ctrl/Cmd+Shift+Z redoes. Arrow keys focus notes; Enter selects.

Snap to scale/key constrains pitch edits and highlights notes and rows in the current scale. Toggle it off for chromatic editing. Existing notes remain unchanged when toggling.
